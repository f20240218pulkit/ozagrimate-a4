# OzAgriMate A4 prototype - runtime dependencies
#
# None. All three services use only the Python 3.10+ standard library
# (http.server, json, dataclasses, threading). `pip install -r requirements.txt`
# therefore installs nothing and is safe to run.
#
# Optional tooling, not needed to run or test the API:
#   Pillow>=10   regenerates diagrams/*.png from diagrams/src/*.py
#   Postman (or Newman) runs the collections in postman/
